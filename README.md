# Maureen Wepngong — Canva Template Portfolio

Public, no-login portfolio of ten original Canva templates by Maureen Wepngong, prepared for a Canva Creators (Template Creator) application.

Live site: https://maureenblack.github.io/canva-portfolio/

The templates are bilingual English/French designs for African life events, small businesses and churches, including a social post set and a presentation deck.

This repository is a static site for GitHub Pages. It does not modify [maureenblack.github.io](https://github.com/maureenblack/maureenblack.github.io).
